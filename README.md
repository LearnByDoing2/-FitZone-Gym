# FitZone Gym

Static gym website built with pure HTML and CSS.

## Description

FitZone Gym is a simple one-page website that presents a gym business.  
It includes sections for services, training programs, about, testimonials, contact details, and a photo slider.

This project is **front-end only** — no backend and no frameworks.

## Technologies Used

- HTML5
- CSS3
- Font Awesome (icons via CDN)

## How to Run

Open the project using any of these methods:

### Option 1 – Direct
Double-click `index.html` and it will open in your browser.

### Option 2 – VS Code
Right click `index.html` → **Open With Live Server**

## Notes

- Images must be inside the `images/` folder.
- The contact form is visual only (no backend).
- Google Maps and YouTube are embedded using iframes.
